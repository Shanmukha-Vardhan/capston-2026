\begin{frame}{Research Gaps}
{\normalsize\textit{Existing assistive solutions focus on simple obstacle presence but lack contextual scene reasoning, require expensive dedicated hardware, or fail to handle unstructured Indian roads.}}\\[10pt]

\begin{columns}[T]
  \begin{column}{0.48\textwidth}
    \textbf{\textcolor{MyUnivGreen}{Gap 1: Expensive Dedicated Hardware}}\\[2pt]
    Systems like SmartCane, Echo-Vision, and ALVU require custom sensors (LiDAR, ultrasonic modules, smart glasses), creating severe cost barriers in developing nations.\\[8pt]
    
    \textbf{\textcolor{MyUnivGreen}{Gap 2: Limited Scene Semantics}}\\[2pt]
    Existing aids only indicate obstacle presence or bounding boxes without contextual understanding. No reviewed system leverages Vision-Language Models (VLMs).
  \end{column}
  
  \begin{column}{0.48\textwidth}
    \textbf{\textcolor{MyUnivGreen}{Gap 3: Lack of End-to-End Integration}}\\[2pt]
    No single solution unifies real-time obstacle detection (YOLO), scene description (VLM), GPS navigation, OCR reading, and conversational voice interaction.\\[8pt]
    
    \textbf{\textcolor{MyUnivGreen}{Gap 4: Unstructured Indian Road Context}}\\[2pt]
    Indian roads present unique hazards (potholes, stray animals, vendors, broken pavements) that existing Western-benchmarked models fail to handle.
  \end{column}
\end{columns}
\end{frame}
