\begin{exampleblock}{Well-Defined Objectives Addressing Identified Gaps}
\begin{enumerate}
    \setlength\itemsep{1em}
    \item \textbf{Develop a Cross-Platform Smartphone Application:}
    Design and build an accessible mobile application (React Native/Expo) delivering real-time assistance directly on commercial smartphones, eliminating the need for expensive dedicated hardware.
    
    \item \textbf{Integrate AI Object Detection \& Contextual Scene Understanding:}
    Deploy an optimized YOLO edge model for low-latency obstacle identification (vehicles, pedestrians, potholes) alongside Gemini Vision-Language Models for deep semantic environmental description.
    
    \item \textbf{Enable Voice-Guided GPS Navigation \& OCR Reading:}
    Incorporate turn-by-turn auditory routing via GPS, OCR capability for reading signboard and transit text aloud, and a hands-free conversational voice interface (STT/TTS).
\end{enumerate}
