Introduction

The Problem

Visually impaired individuals face significant daily challenges in independent mobility and navigation, especially in unstructured Indian road environments. Current assistive tools like the traditional white cane provide limited obstacle awareness with no contextual understanding of the surroundings.

Current Reality

  • Person listens to traffic or asks someone for help when crossing a busy road
  • White cane detects some obstacles on footpaths but cannot identify them
  • Potholes and broken roads are difficult to identify before stepping into them
  • Cannot visually read road signs, bus numbers, or destination boards
  • Finding specific places like bus stops, hospitals, or pharmacies requires asking others

Our Approach

A smartphone-based application that leverages AI, computer vision, and GPS to provide real-time obstacle detection, scene understanding, navigation guidance, and voice interaction — all without requiring specialised or expensive hardware.

Research Gaps

Summary of Literature Review Observations

While several assistive systems exist for visually impaired individuals, most are limited in scope — either focusing solely on obstacle detection without navigation, requiring expensive specialised hardware, or lacking comprehensive scene understanding for complex Indian road environments.

Gap 1: Expensive Specialised Hardware

Most existing systems (SmartCane, Echo-Vision, ALVU, IoT Vision-Aid) require dedicated hardware like LiDAR sensors, ultrasonic modules, smart glasses, or Arduino controllers — increasing cost and reducing accessibility for users in developing countries.

Gap 2: Limited Scene Understanding

Existing solutions primarily detect obstacle presence/distance but lack rich semantic scene understanding. No reviewed system uses modern Vision-Language Models (e.g., Gemini API) to provide contextual descriptions of the environment.

Gap 3: No End-to-End Integrated Solution

No single reviewed system combines real-time object detection (YOLO), AI-powered scene understanding (VLM), GPS navigation, OCR text reading, voice interaction (STT/TTS), and emergency features in one smartphone-based application.

Gap 4: Unstructured Indian Road Contexts

Most systems are designed for structured environments. Indian roads present unique challenges — potholes, blocked footpaths, mixed traffic, vendors, construction zones — that are not adequately addressed by existing solutions.

Problem Statement

Visually impaired individuals face significant challenges in independent navigation, especially in unstructured Indian road environments characterised by potholes, mixed traffic, blocked footpaths, and complex intersections. Current assistive technologies either require expensive specialised hardware (LiDAR, ultrasonic sensors, smart glasses) or provide limited functionality — detecting obstacles without contextual understanding. There is a critical need for an affordable, smartphone-based assistive navigation system that combines real-time object detection, AI-powered scene understanding, GPS navigation, text recognition, and voice interaction to enable safe, independent mobility.

Research Objectives

Well-defined objectives addressing the identified research gaps

1
Develop a cross-platform smartphone application
Build a React Native (Expo) application that provides real-time obstacle detection and navigation assistance for visually impaired users — eliminating the need for expensive specialised hardware.
2
Integrate AI-powered object detection and scene understanding
Implement YOLO-based real-time detection for vehicles, pedestrians, potholes, and obstacles; and integrate the Gemini API (Vision-Language Model) for contextual scene interpretation and intelligent assistance.
3
Enable GPS-based navigation with voice-guided interaction
Provide turn-by-turn audio directions using GPS + Maps integration, OCR for reading signs/text aloud, and full voice interaction via Speech-to-Text and Text-to-Speech — creating a completely audio-first interface.
